# Robot Tuning Logger (บันทึกการจูนหุ่น)

เว็บแอพไฟล์เดียว สำหรับกดบันทึกอาการของหุ่นระหว่างจูน พร้อมจับเวลา

## ฟีเจอร์
- 5 ปุ่ม: เวลาขาด, เวลาเกิน, เลี้ยวผิด, แรงไป, สะบัด ส่าย
- บันทึกลำดับที่กด, เวลาตอนกด (นาที:วินาที.ทศนิยม), นาฬิกาจริง และครั้งที่กดของแต่ละอาการ
- แสดงจำนวนครั้งในวงเล็บบนปุ่ม
- รีเซ็ตเพื่อเริ่มนับใหม่ทั้งหมด, หยุด/เริ่มเวลาต่อ, ลบอันล่าสุด, สลับลำดับรายการ, คัดลอกบันทึก

## วิธีใช้
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย

## ใช้ผ่าน GitHub Pages
1. อัปโหลดไฟล์ `index.html` ขึ้น repository
2. ไปที่ Settings > Pages
3. เลือก Branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
4. เปิดลิงก์ที่ได้ (เช่น `https://<username>.github.io/<repo>/`) บนมือถือได้เลย
